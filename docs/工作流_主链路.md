# 工作流 · 主链路

> **先看你有什么硬件**，再决定走哪条链。这三条共用同一套「分镜 → 配音 → 合成」后端，
> 差别只在第 ③ 步画面怎么来。
>
> 不确定自己缺什么，先跑 `python tools/doctor.py`。

## 一、选路（决策树）

```
                 小说文本
                     │
                     ▼
              ① 分镜切分（scripts/shoot.py::split_sentences）
                     │
        ┌────────────┼────────────┐
        ▼            ▼            ▼
   有 N 卡？     有云端 key？   都没有
        │            │            │
        ▼            ▼            ▼
  ComfyUI 链     云端 provider   QuickCut
  (flow.py)      --engine cloud  --engine quickcut
        │            │            │
        └────────────┴────────────┘
                     │
                     ▼
        ② 配音（Edge-TTS / 阶跃星辰 / CosyVoice2）
                     │
                     ▼
        ④ 合成（xfade 转场 + ASS 字幕烧录 + BGM）
                     │
                     ▼
                   成片 mp4
```

**本机（AMD 核显 / 32 线程 / 无 CUDA）走这条**：

| 步骤 | 用什么 | 画面来源 |
|---|---|---|
| 快 | `--engine quickcut` | 程序化底图 + Ken Burns 推镜 |
| 真 | `--engine ltx` | LTX-Video 2B 本地扩散模型 |

## 二、QuickCut 链（30 秒出片，零依赖）

只想验证链路通不通，或者没有显卡也没有 key —— 走这条。

```bash
# 用包内示例故事
python scripts/shoot.py --demo --out output/film_demo.mp4

# 用自己的小说（推荐先这样试）
python scripts/shoot.py --novel story/last_train.txt --voice 晓伊 --out output/a.mp4

# 限制镜头数 / 换分辨率 / 换转场
python scripts/shoot.py --novel 我的小说.txt --max-scenes 8 --width 1080 --height 1920 \
    --transition fade --zoom 0.0006 --out output/a.mp4
```

**实测**：132 字 → 5 镜头 → 40.9 秒成片，耗时 25 秒。

产物：`<out>.mp4` + `<out>.ass`（字幕）+ `manifest.json`（每镜时长、字幕时间轴、文本清单）。

## 三、LTX 链（真 AIGC 画面，本地扩散模型）

画面是真生成的，不是底图。代价是时间和磁盘。

### 3.1 装依赖（一次）

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements-ltx.txt
```

> `torch` 必须走官方 CPU 索引。默认 PyPI 源给的是 CUDA 版（2 GB+），本机用不上。

### 3.2 下权重（一次，23.5 GB）

放到**仓库根 `models/ltx/`**（已 gitignore）。约 30 分钟。

```
① ltxv-2b-0.9.8-distilled-fp8.safetensors        4.2 GB
② vae/diffusion_pytorch_model.safetensors        1.6 GB
③ text_encoder/model-0000{1..4}-of-00004.safetensors  17.8 GB
④ transformer/config.json、tokenizer/*、scheduler/*、model_index.json
```

仓库自带多源多线程下载器（hf-mirror 超时会自动切 ModelScope）：

```bash
python tools/fast_download.py --repo hf:Lightricks/LTX-Video \
    --file ltxv-2b-0.9.8-distilled-fp8.safetensors \
    --out models/ltx/ltxv-2b-0.9.8-distilled-fp8.safetensors --threads 8
```

下完必须自检，别等跑管线才崩：

```bash
python tools/verify_ltx_weights.py            # 查完整性 + 能否加载
python tools/verify_ltx_weights.py --render   # 再真出 9 帧，确认不是黑屏
```

### 3.3 出片

```bash
export CODEBUDDY_SAFE_DELETE_ENABLED=0     # 必看下方「坑」
python scripts/shoot.py --novel story/qingnang_yuye.txt --engine ltx \
    --width 1024 --height 576 --fps 24 --max-scenes 5 --voice 云健 \
    --out output/qingnang_ltx.mp4
```

### 3.4 速度参考（本机 32 线程实测）

CPU 吞吐约 **120 token/s**，token = `(宽/32) × (高/32) × 帧数`。

| 规格 | 帧数 | 实测 |
|---|---|---|
| 256×256 | 9 | 16 s |
| 512×288 | 192 | 3.9 min |
| 768×448 | 25 | 1.0 min |
| **1024×576** | 120 | **10–14 min/镜** |
| 1280×704 | 120 | 约 20 min/镜 |

5 镜头整片：1024×576 ≈ **61 分钟**，1280×704 ≈ **100 分钟**。

## 五、ComfyUI 链（需要 NVIDIA 显卡）

`scripts/flow.py` + ComfyUI（:8188）+ Wan2.2-TI2V-5B + SDXL 关键帧。
**本机没有可用 GPU 后端，这条跑不了**，换到有 N 卡的机器上再看：

```bash
python scripts/flow.py --cast --style --neg base,face
python scripts/flow.py --dry-run          # 先看会做什么
python scripts/flow.py --only 4 8 12      # 断点续跑，只补指定场景
python scripts/flow.py --skip-render      # 渲染已完成，只跑配音+封装
```

状态在 `output/novel_demo_v2/run_state.json`，按「参数指纹」判断是否重做。

## 六、坑（都真实踩过）

| 现象 | 原因 / 解法 |
|---|---|
| 长任务跑到第 2 个镜头就中断 | 清理上百个中间帧 PNG 触发 safe-delete 批量确认（阈值 50）。**跑之前 `export CODEBUDDY_SAFE_DELETE_ENABLED=0`** |
| `height and width have to be divisible by 32` | 尺寸必须被 32 整除。768×432 不行，用 768×448 / 1024×576 / 1280×704 |
| `ValueError: Invalid voice '晓晓'` | 已修复，音色别名统一走 `engines/tts.py::resolve_voice()` |
| 找不到权重 | 必须在**仓库根** `models/ltx/`。以前代码多写了一层 `.parent` 指向上一级，已修正 |
| 小配置文件下不下来 | `fast_download.py` 对 HEAD 拿不到大小的文件会判失败，**但文件其实已下载成功**，先去磁盘确认再决定是否重下 |
| `--max-scenes 1` 却等很久 | 全部分句被并成一段，帧数顶到 192 上限。要试跑就用小尺寸 + 正常分镜数 |
| 日志被降级提示刷满 | 已修：同一原因只提示一次（`engines/registry.py::_warn_once`） |
| 成片在浏览器卡住不播 | moov 在文件尾部，重跑一次会自动封装成 faststart |

## 七、怎么判断画面是不是真生成的

用相邻帧差的空间标准差（σ）判定：整帧平移（推镜）时 σ ≈ 0，局部内容真动时 σ 明显大于 0。

| 来源 | 帧间差 σ |
|---|---|
| QuickCut 程序化底图 | 0.1 – 1.3 |
| LTX 本地生成 | 7.4 – 13.2 |
| 参考成片（ComfyUI + Wan） | 4.5 – 7.6 |
