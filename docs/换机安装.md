# 换机安装指南

项目代码已在 GitHub（`WJQ341204/naizui`），换任何一台机器都能装。
**关键：权重不用重下**——把已下好的 `models/` 目录整个拷走即可（本机 LTX 全套已完整）。

---

## 方式 A：带权重迁移（推荐，省下载）

### 1. 拷贝两个东西到新机器

| 源 | 目标 | 大小 |
|---|---|---|
| `models/` 整个目录 | 新机器的工作区根目录（与项目**同级**） | LTX 23.5 GB（H3 部分另算） |
| 项目代码 | 走 git clone，或直接拷目录 | 约 300 MB |

目录结构必须保持这样（`models` 和项目**平级**）：

```
工作区/
├── models/                 ← 权重在这里
│   ├── ltx/
│   │   ├── ltxv-2b-0.9.8-distilled-fp8.safetensors   (4.155 GB)
│   │   ├── vae/diffusion_pytorch_model.safetensors    (1.679 GB)
│   │   └── text_encoder/model-0000{1..4}-of-00004.safetensors (17.74 GB)
│   └── minimax-h3/
└── novel-to-video-codex/   ← 项目代码
```

拷贝方式任选：移动硬盘、U 盘、局域网共享、`robocopy /E`、或 `scp`。

### 2. 新机器上装环境

```bat
git clone git@github.com:WJQ341204/naizui.git novel-to-video-codex
cd novel-to-video-codex
python -m venv venv
venv\Scripts\pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple
```

> pip 必须用阿里源，清华源在这台/这类环境会返回空列表装不上。

### 3. ffmpeg（要含 `xfade` + `libass`）

最省事的做法——让 pip 装一个自带二进制的版本：

```bat
venv\Scripts\pip install imageio-ffmpeg
python -c "import imageio_ffmpeg,shutil;print(imageio_ffmpeg.get_ffmpeg_exe())"
```

把打印出的 `ffmpeg.exe` 拷到 `tools\ffmpeg\bin\`，再配 `.env`：

```
FFMPEG_PATH=<工作区>\tools\ffmpeg\bin
```

gyan essentials 精简版**不含 GPL 的 xfade 滤镜**（拼转场必需），别用那个。

### 4. 配 `.env`

复制 `.env.example` 为 `.env`，至少确认这几项：

```
LTX_MODEL_DIR=<工作区>\models\ltx        # 权重实际路径
MODEL_DIR=<工作区>\models
FFMPEG_PATH=<工作区>\tools\ffmpeg\bin
TTS_ENGINE=edge                          # 零 API key 可用
```

### 5. 验证

```bat
python tools\verify_ltx_weights.py          :: 校验权重完整 + 能加载
python tools\verify_ltx_weights.py --render  :: 真出 9 帧确认不是黑屏
python scripts\shoot.py --demo --engine quickcut --images dataset\yhkf --out out.mp4
```

## 方式 B：全新安装（不带权重）

代码步骤同上，权重用分段下载器拉（比 `curl` 快得多）：

```bat
python tools\fast_download.py --repo hf:Lightricks/LTX-Video ^
  --file ltxv-2b-0.9.8-distilled-fp8.safetensors ^
  --out ..\models\ltx\ltxv-2b-0.9.8-distilled-fp8.safetensors --threads 12

python tools\fast_download.py --repo hf:Lightricks/LTX-Video ^
  --file vae\diffusion_pytorch_model.safetensors ^
  --out ..\models\ltx\vae\diffusion_pytorch_model.safetensors --threads 8

:: T5 四个分片（17.74 GB，最大的一块）
for %%i in (1 2 3 4) do (
  start python tools\fast_download.py --repo hf:Lightricks/LTX-Video ^
    --file text_encoder\model-0000%%i-of-00004.safetensors ^
    --out ..\models\ltx\text_encoder\model-0000%%i-of-00004.safetensors --threads 4
)
```

> 实测：hf-mirror **按单个文件限速**，多文件并行才能叠加总带宽；
> 单连接只有 27 KB/s，12 线程分段能到 4-10 MB/s。

## 新机器有 NVIDIA 显卡时（含 Y9000P 这类笔记本）

### 先确认显存够不够

```bat
nvidia-smi
```

看右上角的显存容量，**决定你能跑哪个模型**：

| 显存 | LTX-Video 2B（fp8） | MiniMax-H3 |
|---|---|---|
| 8 GB（RTX 4060/4070 笔记本，Y9000P 2024 常见） | ✅ **流畅** | ❌ 不够 |
| 12 GB（RTX 4080 笔记本） | ✅ 流畅 | ❌ 不够 |
| 16 GB（RTX 4090 笔记本） | ✅ 流畅 | ⚠️ 勉强，容易 OOM |
| 24 GB+（台式 3090/4090/A5000） | ✅ 流畅 | ✅ 可以 |

> ⚠️ **Y9000P 2024（32G 内存 + 1T）配的是 8GB 显存的笔记本卡，H3 跑不动**。
> H3 是 30B 模型，fp8 权重就要 20 GB 常驻，官方建议 24GB+ 显存。
> 别为了跑 H3 折腾，LTX 在这台机器上才是性价比之王。

### 装 CUDA 版 PyTorch

先 `nvidia-smi` 看驱动支持的 CUDA 版本（右上角 `CUDA Version: xx.x`），然后装对应的：

```bat
:: CUDA 12.1（驱动 >= 530）
venv\Scripts\pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

:: 或用国内镜像更快（阿里）
venv\Scripts\pip install torch torchvision -i https://mirrors.aliyun.com/pypi/simple
```

装完验证 GPU 真的可用：

```bat
venv\Scripts\python -c "import torch;print(torch.cuda.is_available(), torch.cuda.get_device_name(0), torch.cuda.get_device_properties(0).total_memory/1e9)"
```

应输出 `True` + 显卡名 + 显存 GB。

### 代码会自动用 GPU，不用改

`engines/video_local.py` 里已有：

```python
if torch.cuda.is_available():
    pipe = pipe.to("cuda")
```

所以只要 torch 是 CUDA 版，**`--engine ltx` 自动走 GPU，无需任何改动**。

### 8GB 显存的推荐参数

| 参数 | 建议 | 说明 |
|---|---|---|
| 分辨率 | 512×768（默认） | 8GB 够用；想更快用 384×672 |
| 单镜头时长 | 2-4 秒 | 帧数 = 时长×fps，帧数越多显存占用越高 |
| 采样步数 | 4 步（distilled 权重） | 调大只会更慢，画质提升有限 |

```bat
python scripts\shoot.py --demo --engine ltx --width 512 --height 768
```

若遇 OOM（显存不足），依次降级：缩短镜头 → 降到 384×672 → 加 `--engine quickcut` 兜底。

### 预期速度

| 机器 | LTX 单镜头（约 5 秒片段） |
|---|---|
| 这台 AMD 核显 / CPU（12 线程） | **约 10 分钟** |
| Y9000P RTX 4060/4070（8GB） | **约 20-60 秒** |

快 10-30 倍——这才是换到 N 卡机器最大的收益。

### 想要 H3 的话

得有 24GB+ 显存的机器（台式 3090/4090、A5000 等）。步骤：

1. 装 CUDA 版 PyTorch
2. 起 ComfyUI（8188 端口），装 `MiniMaxH3ImageToVideo` / `MiniMaxH3ReferenceToVideo` 节点
3. 生成工作流：`python tools\build_h3_workflows.py`
4. 出片：`python scripts\shoot.py --demo --engine h3`

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `QuickCut 需要 ffmpeg` | 环境变量没配，或 PATH 里 ffmpeg 不含 libass。设 `FFMPEG_PATH`（可写目录或 exe 全路径） |
| `Unable to load weights from checkpoint` | 权重没下完。跑 `verify_ltx_weights.py`，它会读 safetensors 头部比对声明长度，直接告诉你缺多少 MB |
| `Lightricks/LTX-Video-0.9.5 ... config.json` | diffusers 想联网拉 config 被代理拦（502）。代码已强制 `HF_HUB_OFFLINE=1`，若仍出现说明本地 `transformer/config.json` 缺失 |
| 出片全黑 | `num_frames` 必须满足 `(n-1)%8==0`，否则会被压成 1 帧 |
| `expected flush after ref listing` | git 走 HTTPS 被代理破坏协议 → **用 SSH 推拉** |
