# 使用教程

从装好环境到出第一部片。三种难度递进，挑适合你的那档。

---

## 一、最快上手（先确认链路通）

```bat
:: 20 秒出一片，零显卡零 API key
python scripts\shoot.py --demo --engine quickcut --images dataset\yhkf --out out.mp4
```

跑完得到 `out.mp4`（约 36 秒，4 个镜头，带配音和字幕）。
这一步能成，说明 ffmpeg、TTS、合成链路全通。

---

## 二、三种出片模式

### 模式 A：QuickCut（快，画面来自素材图）

静态图 + Ken Burns 推镜 + 配音 + 字幕。**不需要显卡、不需要 API key。**

```bat
:: 内置示例故事
python scripts\shoot.py --demo --engine quickcut --images dataset\yhkf --out out.mp4

:: 用自己的小说
python scripts\shoot.py --novel 小说.txt --engine quickcut --images 我的图目录 --out my.mp4
```

- 图片按顺序分配给各场景，图多于场景时循环复用，少于时复用最后一张
- 支持 png / jpg / jpeg / webp
- 单目录 20 张图够 20 个镜头

### 模式 B：LTX-Video（真 AIGC，画面由模型生成）

```bat
:: 小尺寸快跑（推荐先试这个）
python scripts\shoot.py --demo --engine ltx --width 256 --height 256 --out out_ltx.mp4

:: 标准竖屏画质
python scripts\shoot.py --demo --engine ltx --width 512 --height 768 --out out_ltx.mp4
```

耗时参考（单个镜头）：

| 机器 | 512×768 | 256×256 |
|---|---|---|
| CPU（12 线程，无显卡） | 约 10 分钟 | 约 1-2 分钟 |
| RTX 4060/4070 笔记本（8GB） | 约 20-60 秒 | 十几秒 |

**帧数规则**：LTX 要求 `(帧数-1) % 8 == 0`，代码已自动对齐，不用管。

### 模式 C：云端（需要 API key）

在 `.env` 里填 key（支持火山方舟、可灵、即梦、Veo、Runway 等 9 家），然后：

```bat
python scripts\shoot.py --demo --engine cloud --out out_cloud.mp4
```

不填 key 时 `auto` 会自动跳过云端，落到本地引擎。

## 三、参数一览

| 参数 | 说明 | 默认 |
|---|---|---|
| `--demo` | 用内置示例故事 | — |
| `--novel 文件` | 用自己的小说文本（.txt/.md） | — |
| `--dialogue 文件` | 用对白 JSON | — |
| `--engine` | `auto` / `quickcut` / `ltx` / `h3` / `h3ref` / `cloud` | `auto` |
| `--images 目录或文件` | 关键帧素材，作各场景首帧 | 无 |
| `--width` / `--height` | 出图尺寸 | **1080 / 1920** |
| `--fps` | 帧率 | **30** |
| `--voice` | 配音音色（云健/云扬/晓晓/晓伊/云希） | 云健 |
| `--transition` | 转场（fade / wipeleft / slideup…） | fade |
| `--zoom` | QuickCut 推镜速度 | 0.0006 |
| `--out` | 输出路径 | — |

> ⚠️ **用 `--engine ltx` 时务必显式指定尺寸**。默认值 1080×1920 是为 QuickCut
> （程序化底图，很快）设的，LTX 在这个分辨率下 CPU 上要跑几小时、8GB 显存会直接爆。
> 推荐显式写 `--width 512 --height 768`，想快就 `--width 256 --height 256`。

## 四、环境准备（新机器）

完整步骤见 `docs/换机安装.md`，最省事是双击 `install_new_machine.bat`。

三个容易踩的点：

1. **目录必须平级**——`models\` 和项目是**兄弟目录**，不是子目录
2. **pip 用阿里源**——清华源在这类环境返回空列表装不上
3. **`.env` 要自己建**——仓库里没有（被 gitignore 挡了），脚本会自动生成

NVIDIA 显卡额外一步（装 CUDA 版 torch）：

```bat
nvidia-smi
venv\Scripts\pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

代码里已有 `if torch.cuda.is_available(): pipe.to("cuda")`，**装完自动用 GPU，不用改代码**。

## 五、进阶

### 让分镜更聪明

默认按句号机械切分。填 `DEEPSEEK_API_KEY` 后按语义拆分镜并生成画面提示词，剧情连贯性更好。

### 让关键帧更精美

装 ComfyUI + SDXL，`comfyui/` 目录已备好 22 个工作流：
`txt2img_ipadapter.json`（角色一致性）、`txt2img_pulid.json`（人脸一致性）、
`kijai_w22_i2v_a14b.json`（图生视频）等。在 `.env` 配好 `COMFYUI_URL` 即可。

### 用 MiniMax-H3（需 24GB+ 显存）

```bat
python tools\build_h3_workflows.py
python scripts\shoot.py --demo --engine h3      :: 首尾帧
python scripts\shoot.py --demo --engine h3ref   :: 参考图
```

8GB 显存的笔记本（如 Y9000P）**跑不了 H3**，引擎会自动降级，不会崩。

## 六、权重管理与校验

```bat
:: 校验权重完整 + 能加载（不联网，读 safetensors 头部比对）
python tools\verify_ltx_weights.py

:: 再真出 9 帧确认不是黑屏
python tools\verify_ltx_weights.py --render
```

下载权重用分段下载器（比 curl 快得多）：

```bat
python tools\fast_download.py --repo hf:Lightricks/LTX-Video ^
  --file ltxv-2b-0.9.8-distilled-fp8.safetensors ^
  --out ..\models\ltx\ltxv-2b-0.9.8-distilled-fp8.safetensors --threads 12
```

> 实测：hf-mirror 按**单个文件**限速，单连接只有 27 KB/s，
> 12 线程分段能到 4-10 MB/s；多个文件并行可以叠加总带宽。

## 七、常见报错

| 现象 | 原因 / 处理 |
|---|---|
| `QuickCut 需要 ffmpeg` | `.env` 里 `FFMPEG_PATH` 没配或路径错（可写目录或 exe 全路径，两种都认） |
| `Unable to load weights from checkpoint` | 权重没下完。跑 `verify_ltx_weights.py`，它会直接告诉你缺多少 MB |
| `Lightricks/LTX-Video-0.9.5 ... config.json` | diffusers 想联网被代理拦。代码已强制离线，若仍出现说明本地 `transformer/config.json` 缺失 |
| 出片只有 1 帧 | `num_frames` 不满足 `(n-1)%8==0`（代码已自动对齐，手工调用时才可能遇到） |
| 显存不足 OOM | 缩短镜头 → 降到 384×672 → 换 `--engine quickcut` 兜底 |
| 配音失败 | Edge-TTS 需要联网；默认音色 `zh-CN-YunjianNeural` |
| 字幕不显示 | ffmpeg 不含 libass，换 imageio-ffmpeg 版本 |
| git push 报 `expected flush after ref listing` | 代理破坏 HTTPS 协议 → **改用 SSH** 推拉 |
